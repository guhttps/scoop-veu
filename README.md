# Bucket do Scoop do Véu

Esconde dados pessoais e segredos antes de o texto chegar à IA e devolve os dados reais na resposta.

```powershell
scoop bucket add veu https://github.com/guhttps/scoop-veu
scoop install veu
```

O manifesto é gerado pelo repositório principal ([guhttps/veu](https://github.com/guhttps/veu), `scripts/atualizar_manifestos.py`) a cada versão.
